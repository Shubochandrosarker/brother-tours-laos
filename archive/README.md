# Archive policy

This directory preserves material that predates the clean 3.0.0 client
release. Archive contents are reference-only and must not be uploaded to
WordPress or included in a production `wp-content` deployment.

## `pre-3.0.0`

Contains the previous working-tree snapshot, the legacy nested project folder,
scratch packages, older release documents, and the root-level skill artifact.
The snapshot was captured while preparing the 3.0.0 worktree from the local
authoritative checkout. The original dirty checkout was not overwritten.

When a future major release is prepared, preserve this directory and add a new
dated archive folder rather than replacing an earlier archive.
