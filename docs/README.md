# Documentation guide

Start with the current 3.0.0 handoff documents:

- `release-3.0.0.md` — release scope and acceptance gates
- `installation.md` — Hostinger/WordPress installation sequence
- `configuration-matrix.md` — environment settings and ownership
- `content-migration.md` — legacy-to-structured content boundaries
- `security.md` — access control and secret handling
- `seo.md` — staging, production, metadata, and redirects
- `operations-api.md` — app/API ownership and security boundary
- `rollback.md` — backup and recovery procedure

The existing architecture, Elementor, Tour Manager, Formistic, SEO, and
integration documents provide deeper technical detail. Where an older document
mentions a previous release number, the current component headers and
`release-3.0.0.md` control the 3.0.0 handoff.

Historical release records and snapshots belong under `archive/` and are not
deployment instructions.
